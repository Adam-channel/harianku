# Harianku

Alat bantu sehari-hari dalam satu halaman web: **catatan uang** (Rupiah), **daftar tugas**, **daftar belanja**, dan **kalkulator patungan**.

**Buka:** https://adam-channel.github.io/harianku/

- Tanpa akun dan tanpa iklan. Data tersimpan di browser/HP masing-masing, tidak dikirim ke server mana pun.
- Bisa dipasang di layar utama HP dan dipakai tanpa internet (PWA).
- HTML, CSS, dan JavaScript biasa, tanpa build atau library.

Panduan lengkap (cara pakai, data, dan cara mengubah kode): [PANDUAN.md](PANDUAN.md)
